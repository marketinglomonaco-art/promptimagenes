# promptimagenes

Generadores de prompts de imagen para Lomonaco, pensados para Magnific (Nano Banana).

| Archivo | Para qué sirve |
| --- | --- |
| `index.html` | Portada con enlaces a los tres generadores |
| `instantaneas.html` | Fotos robadas y editoriales con personas: quién, qué hace, plano, hora y percepción de valor |
| `ficha-producto.html` | Fichas de producto del colchón en set neutro, 2, 4 o 6 imágenes |
| `imagnes-lm.html` | Primer generador "Luz de casa", con modo personas y modo producto |

Cada archivo es una página HTML independiente: se abre directamente en el navegador, sin instalar nada.

## Anatomía del colchón (regla fija en los prompts)

- Delante: lado corto con el logo LOMONACO bordado. Siempre los pies de la cama.
- Detrás: lado corto liso. Cabecero, contra la pared, con las almohadas.
- Laterales: lados largos sin logo, con dos asas horizontales cerca de los extremos; una lleva una M bordada.
- Cinta granate diagonal: una sola, en la esquina derecha de delante.
